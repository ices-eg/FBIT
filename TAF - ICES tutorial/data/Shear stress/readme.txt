This directory contains output from the 8km Shelf model.

Contents:
---------

Shelf 8km bathymetry.dat		text file: longitude, latitude, depth; land/outside domain = -1.00000e+07
Shelf 8km grid.ps			postscript plot of grid
Shelf 8km M2 bed stress.dat		text file: longitude, latitude, M2 bed stress; land/outside domain = 1.00000e+06
Shelf 8km M2 bed stress.doc		word document describing the derivation of M2 bed stresses
